## About This Prototype:

This is the frontend prototype for our Library Management System, a web app with two user roles: Borrowers and Librarians. It follows the sitemap and wireframes from our Milestone 1 design document.

The prototype uses mock data only (stored in JSON files in src/data). There is no backend or database yet. 

## Prerequisites
- Node.js version 18 or newer
- npm (comes with Node.js)

## Installation

1. Unzip the project and open a terminal in the project's root folder (the one containing package.json).

2. Install dependencies: npm install

## Running the Project

Start the development server: 
1. type in terminal: npm run dev

Then open the local URL shown in the terminal in your browser (by default http://localhost:5173).

## Starting

You will be taken to a welcome page, choosing either Borrower or Librarian. Each option will take you to the corresponding page.
